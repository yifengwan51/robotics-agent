\begin{abstract}
Multimodal LLM agents navigate by giving one model every role: it reads the image and its own history, keeps track
of the room, and writes the plan. Small open VLMs, the models a robot can run on board, fail in this role. With the
EB-Navigation benchmark's agent, Qwen3-VL-4B solves \nEBThree\% of the test episodes, and \nEBThreeLong\% when the
target starts behind it. A controlled diagnosis rules out motion planning, since a
geometric planner given the target position solves \nOracle\% of the same episodes, and recognition, since the
model boxes a visible target in \nProbeThreeCommon--\nProbeThreeBase\% of single views. What fails is keeping
spatial state in generated text. We therefore recast the VLM from planner to sensor. \ours (Semantic-to-Metric) is
a training-free navigation agent that asks the VLM only what the current image can answer, whether the target is
visible and where, and keeps all state in metric form. Its hypothesis memory lifts each answer with depth and pose,
accumulates evidence across distinct viewpoints, and withdraws it when a hypothesis should be visible but is not
detected; a search policy and an occupancy-map planner turn the memory into actions. With the same 4-bit model on
one 8\,GB GPU, \ours reaches \nSThree\% (${+}\nGainThree$\,pp), \nSThreeLong\% on Long-horizon episodes, and
\nRGBThree\% from RGB alone, above both fine-tuned 4B agents and seven of ten training-free agents built on larger
models. With Qwen2.5-VL-3B it lifts success from \nEBTwo\% to \nSTwo\%. On RoboTHOR ObjectNav, which requires an
explicit stop, it reaches \nRoboSR\%, above ten published zero-shot agents.
\end{abstract}
