\begin{abstract}
Robots that follow open instructions need vision-language models (VLMs) small enough to run on board, yet
multimodal LLM agents work only at frontier scale. These agents give one model every role: it reads the image and
its own history, tracks the room, and writes the plan. Here we show that small VLMs fail in this role because of
the role, not because they cannot see. On EB-Navigation, Qwen3-VL-4B prompted as the benchmark's agent solves
\nEBThree\% of the test episodes, whereas a geometric planner given the target position solves \nOracle\% and the
model boxes a visible target in \nProbeThreeCommon--\nProbeThreeBase\% of single views; what fails is keeping
spatial state in generated text. We therefore recast the VLM from planner to sensor. \ours (Semantic-to-Metric) is
a training-free navigation agent that asks the VLM only what the current image can answer, whether the target is
visible and where, and keeps all state in metric form: a hypothesis memory lifts each answer with depth and pose,
accumulates evidence across distinct viewpoints, and withdraws it when a hypothesis should be visible but is not
detected. With the model at 4-bit on one 8\,GB GPU, \ours reaches \nSThree\%, ${+}\nGainThree$\,pp over the
benchmark's agent and ${+}\nSOverMod$\,pp over a generic modular agent with the same model, and \nRGBThree\% from
RGB alone, above both fine-tuned 4B agents and seven of ten training-free agents built on larger models. With
Qwen2.5-VL-3B it lifts success from \nEBTwo\% to \nSTwo\%, and on RoboTHOR ObjectNav it reaches \nRoboSR\%. Asking a
small model only what it can see turns it into a competitive navigator.
\end{abstract}
