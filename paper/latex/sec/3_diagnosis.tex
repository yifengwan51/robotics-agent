\section{Why Small VLM Agents Fail}
\label{sec:diagnosis}

\noindent\textbf{Held-out development split.}
EB-Navigation's five test subsets (Base, Common-sense, Complex, Visual-appearance, Long-horizon) use 60 iTHOR
rooms. We use the benchmark's own generator and instruction files to build a development split on the 30
unused rooms (150 episodes; disjoint from the test rooms by construction). All tuning uses only this split. Every number reported in the paper, including the probes and ceilings below,
comes from the full official test set (300 episodes), run once each configuration is frozen.

\noindent\textbf{Recognition probe.}
For every official test episode we render the start view and the three other 90$^\circ$ headings, and ask the
VLM (i) whether the target is visible (the yes/no first-token probability) and (ii) for its bounding box. We then
score against the simulator's instance boxes, which are used only for evaluation. \Cref{tab:probe} reports hit
rate (IoU$\ge$0.3) when the target is visible, boxes produced on frames where it is not, and the 3D error after
lifting a correct box with depth.
