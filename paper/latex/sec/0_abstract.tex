\begin{abstract}
Small open vision-language models (VLMs) are poor embodied navigators when they must plan in text. Prompted with
the EB-Navigation benchmark's own planning interface, Qwen3-VL-4B solves \nEBThree\% of the test episodes and
\nEBThreeLong\% when the target starts behind the agent. The cause is neither recognition nor motion planning: a
geometric planner given the target position succeeds in \nOracle\% of the same episodes, and the model boxes a
visible target of a named or implied category in \nProbeThreeCommon--\nProbeThreeBase\% of single views. The failure lies in the
interface, which makes the model track the target, the room, and its own progress through generated text. We
propose \ours (Semantic-to-Metric), a training-free agent that asks the VLM only what the current image can
answer, namely whether the target is visible and where it is in the frame. A metric hypothesis memory lifts
these answers with depth and pose, accumulates their evidence over distinct viewpoints, discounts hypotheses that
should be visible but are not detected, and selects targets with an optimal-search index; an occupancy-map
planner turns the selection into actions. With the model at 4-bit on one 8\,GB GPU, \ours reaches
\nSThree\% (${+}\nGainThree$\,pp over the benchmark's agent), \nSThreeLong\% on Long-horizon
episodes, and \nRGBThree\% without a depth sensor or simulator pose, using monocular depth whose scale is fixed
by the floor in every frame. With Qwen2.5-VL-3B it reaches \nSTwo\% against \nEBTwo\%. On the \nRoboN-episode
RoboTHOR validation split, which requires an explicit stop decision, \ours reaches \nRoboSR\% success, above
ten published zero-shot agents.
\end{abstract}
