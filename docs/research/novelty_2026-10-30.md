## Verdict

- No single algorithmic component is new enough for a CCF-A method paper, and only multi-view fusion has a measured
  effect.  Defensible contribution: an end-to-end, fully reported system result for a 4-bit 3-4B local VLM on two
  full official splits with paired statistics, plus the diagnosis (outcome taxonomy, candidate recall,
  truncation cause of the Qwen2.5 baseline).
- Headline fragility: S2M with estimated depth (exact pose) is 45.7 vs EB prompt 48.0 (-2.3 pp, p = 0.6); the
  advantage on named targets needs accurate depth, the Long-horizon advantage (+36.7 pp) persists.
- Competing numbers: ETP / "Enabling Extensible Embodied Capabilities with Tools" (2605.26637, full) reports
  Qwen3-8B 0.42 -> 0.80 on EB-Nav training-free with tools (whether tools read simulator state was not
  verified).  STRIVE (2505.06729, full) reports RoboTHOR 68.1 / 36.3 with Gemini-2.0-flash in Habitat (split not
  named), above S2M's 59.6 / 35.9.
- Options (decision for the author): (1) reframe as an analysis paper on which decisions a small local VLM can be
  trusted with, under identical inputs; (2) add input-matched baselines (EB prompt given depth/pose as a map or
  tools; AECNav-style fusion with the same VLM as detector); (3) present the index and tiling as implementation
  details, or show them in multi-room scenes (e.g. ProcTHOR).
