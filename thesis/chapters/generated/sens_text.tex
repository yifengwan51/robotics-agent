\Cref{tab:sens} changes the two parameters of the evidence rule one at a time on the test set, after the configuration was frozen, as an analysis rather than a selection. No setting moves success by more than \nSensMaxAbs{} percentage points, so the gain of \ours does not hinge on these values. Only the commit threshold $\tau_\mathrm{c}=1.2$ ($-2.9$\,pp) is significant after Holm correction. A stricter threshold asks for more evidence before the agent commits, which costs steps in an episode limited to 20; the other three settings change success by less than 2 percentage points, with intervals that include zero.
