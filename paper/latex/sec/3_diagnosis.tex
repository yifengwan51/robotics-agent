\section{Why Small VLM Agents Fail}
\label{sec:diagnosis}

\noindent\textbf{Held-out development split.}
EB-Navigation's five test subsets (Base, Common-sense, Complex, Visual-appearance, Long-horizon) use 60 iTHOR
rooms. We use the benchmark's own generator and instruction files to build a development split on the 30
unused rooms (150 episodes; disjoint from the test rooms by construction). All tuning uses only this split. Every number reported in the paper, including the probes and ceilings below,
comes from the full official test set (300 episodes), run once each configuration is frozen.

\noindent\textbf{Recognition probe.}
For every official test episode we render the start view and the three other 90$^\circ$ headings, and ask the
VLM (i) whether the target is visible (the yes/no first-token probability) and (ii) for its bounding box. We then
score against the simulator's instance boxes, which are used only for evaluation. The raw probe outputs are retained
under \texttt{runs/grounding/}, but no checked aggregation artifact is available in this snapshot; we therefore do
not use probe numbers to support the reported claims.

\noindent\textbf{Oracle ceilings.}
Given the true target position, our diagnostic geometric planner (\cref{sec:method}) succeeds in 93.3\% on Base,
83.3\% on Long-horizon, and 91.3\% overall on the official 300-episode test set using the depth-built map. This is
an oracle-target diagnostic, not a deployable planner, and is not compared causally with the VLM baselines.

\noindent\textbf{Appearance-only goals are recall-limited.}
The Visual subset is consistently lower than the other S2M subsets in the saved main runs (50.0--56.7\% versus
80.0--91.7\% in the named-object subsets). A targeted candidate-recall analysis remains pending; without a checked
probe aggregation, this pattern should not be attributed to a particular recognition failure mode.

\noindent\textbf{Failure taxonomy.}
Detailed error-taxonomy percentages are intentionally omitted: the analysis script exists, but no saved,
cross-checked aggregate taxonomy is present in the result artifacts.
