\section{Problem and Diagnosis}
\label{sec:diagnosis}

\noindent\textbf{Task.}
An episode gives an instruction $\ell$ that identifies one object with floor position $x^\star\in\mathbb{R}^2$.
At step $t$ the agent observes an RGB frame $I_t$, depth $D_t$, a pose $p_t=(x_t,\theta_t,\phi_t)$ of floor
position, heading, and camera tilt, and the success flag $o_{t-1}$ of its last action, and it chooses
$u_t\in\mathcal{U}$: four 0.25\,m translations, two 90$^\circ$ turns, and two 30$^\circ$ tilts. The episode is
successful if
\begin{equation}
\exists\, t\le T:\ \lVert x_t-x^\star\rVert\le 1\,\text{m},\qquad T=20 .
\label{eq:success}
\end{equation}
EB-Navigation~\cite{yang2025embodiedbench} poses this task in single AI2-THOR rooms~\cite{kolve2017ai2thor}; its
test set has five subsets of 60 episodes. \emph{Base} names the category, \emph{Common} describes the object by
its use, \emph{Complex} embeds it in a longer instruction, \emph{Visual} describes only its appearance, and
\emph{Long} repeats Base with the agent turned away from the target.

\noindent\textbf{The benchmark's agent.}
The benchmark's own agent, the \emph{EB prompt}, maps the image and its text history
$h_t=(u_{0:t-1},o_{0:t-1})$ directly to a plan,
\begin{equation}
(u_t,\dots,u_{t+m})=f(I_t,\ell,h_t),
\label{eq:ebpolicy}
\end{equation}
which is executed until an action fails. All spatial state, where the target was, what the room contains, and how
the agent has turned, must be carried by $h_t$ and the generated reasoning. \ours factorizes the same decision:
\begin{equation}
\begin{gathered}
(\pi_t,b_t)=f(I_t,s),\\
\mathcal{B}_t=g(\mathcal{B}_{t-1},\pi_t,b_t,D_t,p_t),\qquad u_t=\rho(\mathcal{B}_t,p_t),
\end{gathered}
\label{eq:factor}
\end{equation}
where $s$ is a target phrase, $f$ answers only questions about $I_t$, and the metric belief $\mathcal{B}_t$ and the
planner $\rho$ hold all state and every decision (\cref{sec:method,fig:mech}). The configuration of \ours was fixed on a
development split of 150 episodes that we built with the benchmark's generator on 30 iTHOR rooms not used by the test
set.

\noindent\textbf{Planning is not the bottleneck.}
Replacing the target belief of \ours by the true $x^\star$, with the same occupancy map and planner, solves
\nOracle\% of the 300 test episodes (\nOracleBase\% on each of the first four subsets and \nOracleLong\% on Long).

\noindent\textbf{Single views are informative but unreliable.}
For each test episode of the first four subsets we render the start view and the three other 90$^\circ$ headings
and query the VLM with the phrase $s$. Qwen3-VL-4B places a box with IoU${\ge}0.3$ on the visible target in
\nProbeThreeBase, \nProbeThreeCommon, \nProbeThreeComplex, and \nProbeThreeVisual\% of the views on Base, Common,
Complex, and Visual (75 visible instances each). It also errs the other way: on views that do not show the target it
still places a box in \nFalseBoxNamedLo--\nFalseBoxNamedHi\% of the cases for named categories and in
\nFalseBoxVisual\% for appearance-only phrases. A single answer is therefore evidence, not a decision.

\noindent\textbf{The prompted agent loses spatial state.}
We label each failed episode by its first matching outcome: \emph{never seen}, \emph{near miss} (within 1.5\,m),
\emph{lost after seen} (out of view in the last five steps), \emph{blocked} (30\% of actions rejected), oscillation, or
approach failure.
Of the \nFailEBThree{} episodes that the EB prompt fails with Qwen3-VL-4B, \nLostEBThree{} lose a target that was in
view, \nBlockedEBThree{} are blocked by collisions, and \nNearEBThree{} end within 1.5\,m (\cref{fig:analysis}b);
in \nNeverLongEBThree{} Long episodes the agent never brings the target into view.

\noindent\textbf{What the diagnosis predicts.}
If small VLMs fail because their role makes them carry spatial state through text, an agent that keeps this
state outside the model, with the same model and the same actions, should (i)~remove the never-seen and blocked failures
and reduce the lost-after-seen ones; (ii)~gain most on Long, where the target must be remembered across turns;
(iii)~gain least on Visual, where single-view recognition is weakest and stays the limit; and (iv)~depend far less
on the size of the model, which no longer plans (\cref{sec:exp}).
